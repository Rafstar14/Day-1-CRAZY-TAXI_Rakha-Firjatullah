# Building with AI & Prompt EngineeringDefinisi Prompt Engineering
Teknik merancang instruksi agar model AI menghasilkan respons yang tepat, relevan, dan dapat langsung digunakan.   Definisi Prompt: Masukan atau instruksi yang diberikan kepada AI, berbentuk pertanyaan, kata kunci, instruksi kompleks, maupun potongan kode.   Pentingnya Konteks: Pemberian konteks yang detail dan jelas sangat menentukan kualitas serta ketepatan hasil yang diberikan AI.   Struktur Prompt Efektif: Terdiri dari 4 komponen kunci, yaitu Role (peran AI), Task (tugas utama), Context (latar belakang/batasan), dan Format (bentuk luaran yang diharapkan).   Keuntungan Prompt Engineering: Meningkatkan performa AI, meminimalkan bias atau respons yang tidak diinginkan, meningkatkan kontrol dan predictability, serta memberikan pengalaman pengguna yang lebih baik.   

# Management Change dengan Git & GitHubDefinisi Git: 
Sistem Version Control terdistribusi (DVCS) lokal ciptaan Linus Torvalds (2005) untuk mencatat dan melacak setiap perubahan file.   Git Workflow (3 Area Utama):Working Directory: Ruang kerja file lokal tempat modifikasi kode dilakukan.   Staging Area (Index): Tempat menampung perubahan file yang disiapkan untuk commit berikutnya.   Git Directory / Repository: Tempat penyimpanan metadata dan database proyek (.git).   Perbedaan Git vs GitHub: Git merupakan perangkat lunak version control di komputer lokal, sedangkan GitHub adalah platform berbasis web untuk menyimpan repository Git secara daring dan berkolaborasi.   

Perintah Dasar Git (Essential Commands)
1. git init: Menginisialisasi repository lokal baru.
2. git add . / git add -A: Memindahkan file yang diubah ke staging area.
3. git commit -m 'message': Menyimpan perubahan dari staging area ke repository.
4. git remote add <name> <url>: Menghubungkan repository lokal dengan repository remote.
5. git push origin main: Mengirim commit lokal ke repository remote di GitHub.
6. git pull origin main: Mengambil dan menggabungkan perubahan dari remote ke repository lokal.
7. git clone "url": Mengunduh/menyalin repository dari GitHub ke komputer lokal.
   
Konfigurasi & Setup SSH Key: Dokumen menjelaskan alur instalasi Git, pengaturan identitas, pembuatan SSH Key, konfigurasi SSH agent/Keychain pada macOS, dan penautan public key ke akun GitHub untuk otentikasi yang aman.
