# Kalkulator Interaktif

Kalkulator interaktif berbasis HTML murni, tanpa dependensi eksternal.

## Fitur
- Operasi dasar: tambah, kurang, kali, bagi
- Persen dan ubah tanda (+/-)
- Riwayat kalkulasi (tersimpan di localStorage, maks 20 entri)
- Input keyboard penuh
- Responsif di semua ukuran layar
- Aksesibel: navigasi keyboard, focus indicator, ARIA labels

## Cara Pakai
Buka `index.html` langsung di browser. Tidak perlu server atau build step.

## Keyboard Shortcuts
| Tombol | Aksi |
|--------|------|
| `0-9` | Input angka |
| `. / ,` | Desimal |
| `+ - * /` | Operator |
| `Enter / =` | Hitung |
| `Escape / Delete` | Hapus semua |
| `Backspace` | Hapus digit terakhir |
